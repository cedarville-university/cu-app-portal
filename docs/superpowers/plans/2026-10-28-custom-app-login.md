# Custom App Login Implementation Plan

**Goal:** Replicate the History4U login fix in new Next.js apps and help owners update existing apps.

**Design:** Generate an anonymous, branded `/login` page with an Auth.js server action; retain session protection and the existing Entra callback. Version Next.js starters at 1.1.0. Show older Next.js sign-in apps a dismissible app-details notice with a reviewable, copyable Codex prompt. Remember dismissal per user and app in the current browser; tolerate unavailable browser storage. Imported Next.js sign-in apps remain eligible because their code is not regenerated by the portal.

**Constraints:** No Azure changes, existing-repository rewrites, or deployments. Public apps and FastAPI apps do not need this notice. Preserve safe return destinations and handle sign-in errors without swallowing framework redirects. Existing callbacks and public health checks remain unchanged.

- [x] Add failing generation tests for public login, safe return URLs, server-action sign-in, errors, and protected lookalike paths.
- [x] Update conditional template files and Next.js template versions.
- [x] Update shared Codex handoff and generated app skill guidance, preserving recognition of the previous canonical skill.
- [x] Test notice eligibility, prompt copying, per-app dismissal, reload persistence, and storage/clipboard failures; integrate above the app-details content.
- [x] Update setup/template docs; run affected tests and production build, then review the diff.
